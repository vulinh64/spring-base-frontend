# `app/_lib/components/common`

This folder contains cross-feature UI primitives and behaviors, including pagination, loading and error states, toasts, confirmation dialogs, search, Markdown editing/rendering, table of contents, and embedded YouTube playback. The root App Router loading fallback and error boundary reuse `LoadingSpinner` and `ErrorBanner`.

`MarkdownRenderer.tsx` is compatibility-sensitive because stored posts may rely on GFM, raw HTML, alerts, highlighting, heading anchors, and custom YouTube elements. Post detail pages parse Markdown H2 headings into a table-of-contents model containing deterministic IDs and source offsets, then the renderer binds each Markdown heading to that exact model entry. Raw HTML headings keep independent fallback IDs that reserve all table-of-contents IDs, and active-section tracking considers only IDs from the Markdown-derived model. The renderer gives repeated H2 text deterministic numbered anchor IDs for compatibility with existing stored posts; new and edited posts block duplicate base anchors before submission. Pagination hides page navigation when the backend reports zero pages while retaining an available page-size selector. Shared feedback components should remain the default for mutations and destructive actions; confirmation dialogs must receive mutation pending state to prevent duplicate submissions.
